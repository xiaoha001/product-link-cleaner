# 商品链接净化复制助手

用于 Tampermonkey（油猴）的独立脚本。在淘宝、天猫和京东的电脑端商品详情页右下方显示 **“转链并复制”** 按钮，点击后将整理后的链接复制到剪贴板。

这里的“转链”是按需求删除无关参数，不涉及返佣推广链接、短链接或第三方转链接口。

## 安装与使用

1. 在浏览器中安装并启用 Tampermonkey 扩展。
2. 点击 Tampermonkey 图标，选择“添加新脚本”（也可能显示为“创建新脚本”）。
3. 用文本编辑器打开本目录的 `商品链接净化复制.user.js`，复制全部内容，替换新脚本编辑器中的默认内容。
4. 按 **Ctrl+S** 保存，确认该脚本处于启用状态。如果浏览器提示需要允许用户脚本运行，请按扩展提示设置。
5. 打开或刷新商品详情页，点击右下方 **“转链并复制”**，出现“已复制”后即可粘贴使用。

使用脚本不需要 Node.js、不需要登录额外账号，也不需要配置接口或运行服务器。下方的开发验证步骤仅用于修改脚本之后检查功能。

## 转换规则

| 平台 | 支持的详情页 | 输出规则 |
| --- | --- | --- |
| 淘宝 | `item.taobao.com/item.htm` | 保留 `id` 和有效的 `skuId`，先 `id` 后 `skuId` |
| 天猫 | `detail.tmall.com/item.htm` | 保留 `id` 和有效的 `skuId`，先 `id` 后 `skuId` |
| 京东 | `item.jd.com/商品数字ID.html` | 去掉全部查询参数 |

输出统一使用 HTTPS，并去掉地址末尾的 `#` 片段。没有 `skuId` 时不额外添加；无法识别商品的页面不显示按钮。转换过程完全在本地进行，不发送商品链接或页面数据。

## 使用细节

- 每次点击读取浏览器地址栏的当前链接，页面不刷新但地址发生变化时也能使用。
- 淘宝、天猫的规格 ID 来自地址栏。如果选择规格后网站没有更新地址栏，脚本不会猜测页面内部的规格 ID。
- 复制成功后会短暂显示整理后的链接；自动复制受阻时会保留链接框，点击链接可全选，再按 **Ctrl+C**（Mac 为 **⌘C**）手动复制。
- 当前覆盖上表所列的电脑端地址，不覆盖手机端域名、短链接、搜索列表、购物车或天猫国际域名。
- 如果没有出现按钮，先确认油猴及脚本已启用、浏览器已允许用户脚本运行，然后刷新受支持的商品详情页。

## 项目文件与开发验证

- `商品链接净化复制.user.js`：直接安装使用的完整脚本，无外部运行依赖。
- `tests/`：链接规则及浏览器交互验证。
- `预览-复制成功.png`：浏览器验证时保存的界面效果图。

在此目录运行：

```powershell
npm test
npm install
npm run test:browser
```

`npm test` 使用 Node.js 内置测试工具；浏览器验证依赖本机安装的 Chrome。若希望使用 Edge，可将 `playwright.config.cjs` 的 `channel` 改为 `msedge`。

浏览器验证会拦截商品页请求，使用本地样例检查三个平台的按钮、复制结果、剪贴板备用通道、复制失败处理、动态规格地址和窄屏布局，不访问真实电商页面。脚本管理器的真实授权与电商页面的最终兼容性仍应以安装后的实际使用为准。

2026-11-24 已验证：9 项链接规则检查、9 项 Chrome 浏览器交互检查全部通过，包括浏览器实际剪贴板的写入与读回。尚未在已安装 Tampermonkey 的真实电商页面进行验收。
